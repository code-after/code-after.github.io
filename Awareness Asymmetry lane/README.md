# Awareness Asymmetry lane

*Essays on the gap between where AI is a present-tense fact and where it arrives as a future tense from elsewhere.*

> AI does not arrive everywhere at once — and the distance between the societies that live inside it and those that read about it shapes what each can see, and what each can do. This lane collects the essays that name and trace that asymmetry.
