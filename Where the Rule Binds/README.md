# Where the Rule Binds

*Essays on how governance proposals bind — to what object, for how long, and in what units.*

> Every governance proposal finally rests on something an outsider has to check: a statement, a claim, a procedure, a supply chain, a measured physical event. These essays ask what AI governance binds to — and what happens when the object it binds to stops holding.
